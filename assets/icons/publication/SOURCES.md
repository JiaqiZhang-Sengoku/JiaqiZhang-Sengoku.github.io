Publication icon sources
========================

The three WebP icons are 96px renditions of the following Microsoft
[Fluent Emoji](https://github.com/microsoft/fluentui-emoji) Color SVGs:

- `paper.webp`: Memo
- `web.webp`: Globe showing americas
- `huggingface.webp`: Hugging face

They are used under the MIT license in `LICENSE-FLUENT-EMOJI.txt`.
The Code and GitHub links reuse `../profile/github.svg`.
