Missing-modality lens

Recover what is missing, without inventing everything.

With video missing, PriMD uses the shared semantics of text and audio to retrieve constrained visual primitives.

Shared query
Primitive memory
Student state Constrained compensation

Core insight

The missing modality is not one indivisible representation.

Holistic generation, alignment, or distillation mixes information that can be reliably inferred with details that remain fundamentally uncertain.

PriMD starts from an intra-modal view: each modality contains two different kinds of knowledge, and they should not be recovered in the same way.

Shared semantics

Cross-modal emotional evidence that remains relatively consistent and can be estimated from the observed modalities.

Modality-specific information

Expression details tied to text, voice, or appearance. When a modality is absent, these details are uncertain and require constrained compensation.

Method

Disentangle, discretize, then retrieve.

A complete-modality teacher builds structured knowledge; an incomplete-modality student retrieves only the primitives needed for the current missing pattern.

01

SSSD

Shared-Specific Semantic Decoupling

Separates cross-modal shared semantics from modality-specific representations before knowledge transfer.

02

DPMC

Discrete Primitive Memory Construction

Quantizes specific representations into learnable prototypes and forms one frozen memory bank per modality.

03

DRAD

Dynamic Retrieval Augmented Distillation

Uses visible shared semantics to select a sample-dependent number of relevant primitives for the missing modalities.

Inside primitive memory

The memories learn modality-specific, emotion-related usage patterns.

Retrieval is neither random nor concentrated on one fixed prototype. Each modality develops a distinct primitive distribution, while emotion classes activate different subsets.

Text

Class-specific peaks emerge at different primitive IDs, preserving lexical emotion cues.

Audio

The learned distribution shifts to voice-specific prototypes rather than copying the text bank.

Visual

Facial-expression evidence activates a separate set of primitives with its own class structure.
